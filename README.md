# SlavyaWearable Catalog

Public, curated Watch Face Format catalog for SlavyaWearable.

Contains installable bundles, original previews, authors, pinned upstream revisions, checksums and licenses. The application source is maintained separately in a private repository. No health records, notification contents, signing keys or user imports are published here.

New catalog versions are picked up by the app without reinstalling it. Each prepared APK passes the official Google Watch Face Push validator. Upstream designs retain their own licenses, included alongside the bundles and inside each APK. Adaptations change the package namespace and manifest for Watch Face Push.
